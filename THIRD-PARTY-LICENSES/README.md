# ZafBot third-party license files

This directory was generated by `collect_zafbot_licenses.py` from the active Python environment.

- `STANDARD-LICENSE-TEXTS/` contains canonical SPDX license texts.
- `PACKAGES/` contains original license, copyright, AUTHORS, COPYING and NOTICE files collected from installed distributions, or extracted from exact-version PyPI source distributions when the installed package did not expose these files.
- `SOURCE-CODE/` contains the exact Certifi source distribution for the installed Certifi version (MPL-2.0).
- `COLLECTION-REPORT.txt` records package versions, metadata license declarations, and any collection gaps.

Keep this directory together with `THIRD-PARTY-NOTICES.md` when redistributing the corresponding build. Review the report before publishing.
